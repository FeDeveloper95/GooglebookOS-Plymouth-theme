## Install

Clone the repo and run the installer:

```bash
git clone [https://github.com/FeDeveloper95/GooglebookOS-Plymouth-theme.git](https://github.com/FeDeveloper95/GooglebookOS-Plymouth-theme.git)
cd GooglebookOS-Plymouth-theme
sudo ./install.sh
```
